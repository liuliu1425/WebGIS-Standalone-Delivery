本文帮助接收方沿用现有结构修改代码。部署与运行统一从 [部署与运行](部署与运行.md) 所述入口开始。

## 2. 建立开发基线

以实际交付清单、源码指纹与验收记录为基线，在自己的开发分支修改。配置和运行数据保存在独立位置，不把凭据或生成缓存纳入源码提交。

依赖以现有锁文件和清单为准。新增依赖前先确认现有组件是否已提供相同能力，并记录对构建与部署的影响。

## 3. 助手操作约定

| 操作 | 含义 |
|---|---|
| 添加 | 加入图层列表；默认隐藏，不抢当前选中对象 |
| 显示或勾选 | 显示并选中目标；普通显示不隐藏其他图层 |
| 隐藏 | 取消显示；隐藏图层仍可保持选中 |
| 选中或切换到 | 仅切换查看对象；保持目标显隐，时间轴跟随其独立日期 |
| 修改指定图层日期 | 只改目标层记忆日期；其他图层的日期与显隐保持 |
| 只显示 | 明确显示目标并隐藏其他适用图层 |

图层显示名用于阅读，执行使用稳定图层和实例标识。来源、平均版或动态版、变量和日期应分别绑定，无法唯一确定时返回澄清。

优先检查 request_semantics.py、layer_reference.py、layer_identity.py、operation_plan.py 与 orchestrator.py 的共用流程。前端执行入口位于 agent-ui-intent.ts；多步骤等待和引用衔接位于 agent-operation-runner.ts。提示词及工具参数必须与实际执行行为保持一致。

查询只读取实时状态。操作提交不代表完成；回执应区分执行结果、数据就绪与实际渲染。不得让模型或本地规则凭提交成功编造取数成功。

## 4. 流式对话与停止

stream_recovery.py、agent_router.py、agent-api.ts 与 AgentChatPanel.vue 共同处理流式连接中断。连接中断后读取同一请求结果，不重新提交原操作。

该恢复记录保存在单个 API 进程的有界内存中，不能视为跨进程、跨重启的持久恢复能力。多实例部署应另行验证路由一致性或采用经过验证的共享实现。

新增请求、停止或切换会话后，旧请求的较晚返回不得覆盖当前状态。修改这条链路时，应同时测试正常完成、中断、主动取消和较晚返回。

## 5. 数据与时序分析

可用日期以选定产品、版本、变量的数据索引为依据；地图当前日期和分析起止时间分别保存。不要用本地显示缓存推断完整数据覆盖。

点位分析提取坐标所在像元；区域分析使用固定的真实几何边界。SM、VOD 等变量使用各自单位、网格及时间间隔。缺失值留空，不补零或默认平滑。

日期索引位于 nas_ondemand/date_index.py，并复用现有 fetcher。该调用需要数据源配置和访问权限；产品未配置、日期缺测、位置超出覆盖及像元无效应分别反馈。

修改数据接口后，前端日期范围、请求参数、数据表和导出说明应一起核对。曲线缩放与表格切换属于结果查看，不应重复分析或修改地图图层状态。

## 6. 配置和外部服务

使用部署初始化生成的外部配置，按现有设置入口或配置协议提供接收方自己的服务。不要将凭据写入提示词、界面代码、日志或样例。

默认出网限制由部署编排控制。开启可选网络通路后，Provider 配置、账号权限与真实数据连通性仍需单独验证。

## 7. 回归方式

以下是开发回归参考命令；本次已经执行的范围见 [交付验收记录](交付验收记录.md)。其他组合按修改内容运行。使用隔离配置与临时数据，固定用例不调用在线模型或真实 NAS。

后端示例：

~~~powershell
python -m pytest -q -p no:cacheprovider Test/backend/test_agent_basic_capabilities.py Test/backend/test_agent_keyword_targets.py Test/backend/test_agent_operation_flow.py Test/backend/test_agent_single_step_regressions.py
python -m pytest -q -p no:cacheprovider Test/backend/test_spatial_timeseries.py Test/backend/test_spatial_timeseries_sources.py Test/backend/test_spatial_timeseries_boundary_merge.py
~~~

NAS 索引的模拟入口应指向实际调用模块 nas_ondemand.date_index.daily_index。若从旧用例迁移，不能继续只替换另一个模块的同名函数。

前端在 Code/frontend 下执行：

~~~powershell
npm run test -- agent-api agent-chat-helpers agent-operation-runner agent-ui-intent
npm run test -- spatial-timeseries
~~~

修改交互后，应额外核对实际页面状态；浏览器无法渲染时，记录限制，不把回复文本当作地图已更新的证据。回归结果与版本、配置方式和未验证项共同归档。
